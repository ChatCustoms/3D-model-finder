# 🔍 3D Model Finder Web App

## 📖 Introduction
The 3D Model Finder is a full-stack web application that allows users to search and discover 3D models from Thingiverse.  
It provides authentication, user profiles, and the ability to like/favorite models.  

**Goal:** Make it easier for makers, hobbyists, and engineers to quickly find and save 3D printable models in one place.  

---

## 🛠️ Tech Stack
- **Frontend:** React.js (with JSX, routing, modals, and responsive components)  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB Atlas  
- **Authentication:** JWT-based authentication system  
- **Deployment:** Google Cloud VM (backend), Vercel (frontend)  

---

## 🚀 Features
- 🔐 **User Authentication** – Register and log in securely  
- 👤 **User Profiles** – Personalized profile page with liked models  
- ❤️ **Like/Favorite System** – Save models for future reference  
- 🔍 **Thingiverse API Integration** – Search models directly by keyword  
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile   

---

## 📂 Project Structure
- **/frontend** → React frontend (components, routing, styles)  
- **/backend** → Express server, authentication, and API routes  
- **/utils** → Utility functions and API integrations
